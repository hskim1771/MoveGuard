# 프론트엔드 보호 범위

## 기준

현재 통합 브랜치의 프론트엔드를 유지한다. 과거 작업에서 사용자가 승인한 기준은
`feature/figma-ui-rtmw-integration` 커밋 `17eb855`이며, 현재 변경은 그 위의 통합 브랜치에 있다.

## 필수 화면

### `/dashboard`

- 제목 `작업장 전체 대시보드`
- 새 분석 시작, 개인 분석 기록 버튼
- 오늘 분석 인원, 총 분석 시간, 위험 이벤트, 고위험 작업자
- 작업장 전체 부위별 위험도 모니터와 최근 추이
- 특정 개인이 아닌 작업장 전체 통계

### `/history`

- 제목 `작업자별 분석 기록`
- 작업자 선택과 개인별 기록·부위 위험도·RULA 결과
- 개인 통계와 작업장 전체 통계의 명확한 분리

### `/` 및 `/video-analysis`

- 작업자 선택 → 설정 → 카메라/업로드 → RULA → 리포트 순서
- 원본 영상 프레임을 먼저 그리고 그 위에 스켈레톤을 겹친다.
- 스켈레톤만 단독 표시하지 않는다.
- MediaPipe가 기본 분석 모델이다.
