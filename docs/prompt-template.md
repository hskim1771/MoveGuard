# 다음 작업 요청 템플릿

새 PC나 새 대화에서 아래 내용을 복사해 사용할 수 있다.

```text
MoveGuard 저장소 작업을 이어서 진행해줘.

먼저 루트 AGENTS.md와 요청에 관련된 docs 문서만 읽어줘.
대화 기억이나 추측보다 저장소의 현재 코드와 문서를 기준으로 해줘.

작업 브랜치:
feature/mediapipe-aihub-120k-integration

절대 조건:
- main 수정 또는 merge 금지
- 기존 최신 프론트엔드 교체 금지
- 요청 범위를 벗어난 리팩터링 금지
- 원본 AI-Hub 데이터 수정·이동·삭제·업로드 금지
- confidence를 정확도로 표현 금지
- 전문가 RULA 정확도를 임의로 주장 금지

이번 요청 범위:
[여기에 실제 작업 한 가지를 구체적으로 작성]

완료 전에 관련 테스트와 실제 API 동작을 확인하고,
변경 파일·검증 결과·한계를 보고해줘.
별도 브랜치에만 커밋하고 main에는 병합하지 마.
```

## 좋은 범위 예시

- `업로드 영상 분석 API의 응답 지연만 측정하고 원인을 보고해줘.`
- `전문가 RULA 정답 CSV를 읽는 평가 스크립트만 추가해줘.`
- `/history 화면 디자인은 건드리지 말고 저장 API 오류만 수정해줘.`

## 피해야 할 요청

- `전체를 더 좋게 만들어줘.`
- `알아서 모든 구조를 바꿔줘.`
- `정확도를 높여줘.`

넓은 목표는 데이터, 평가 기준, 변경 가능한 영역, 완료 조건으로 나눠 요청한다.
